# habit · 终端习惯打卡

每天一行命令，把习惯变成看得见的连续天数。纯 Python 标准库，数据存在本地一个 JSON 文件里。

## 快速开始

```bash
python3 -m habit add "锻炼" --target 5   # 添加习惯，每周目标 5 次
python3 -m habit done 锻炼               # 今日打卡
python3 -m habit list                    # 一览：本周进度 + 连续天数
python3 -m habit log 锻炼                # 最近 14 天打卡条
python3 -m habit rm 锻炼                 # 删除（会先确认）
```

输出示例：

```
===== 习惯打卡（2026-10-05）=====

  锻炼 ██████░░░░ 3/5　连续 4 天
  读书 本周 2 次　连续 1 天
```

```
===== 锻炼 最近 14 天 =====
  ░ ░ ▓ ▓ ░ ▓ ▓ ▓ ░ ░ ▓ ▓ ░ ░
   22  23  24  25  26  27  28  29  30   1   2   3   4   5
  共打卡 7 天
```

## 参数

| 命令 | 说明 |
|---|---|
| `add NAME [--target N]` | 添加习惯；`--target` 为每周目标次数（默认 0 = 不设目标） |
| `done NAME` | 今日打卡；同一天重复打卡只算一次 |
| `list` | 全部习惯：本周次数、连续天数、目标进度条 |
| `log NAME` | 最近 14 天的 ▓/░ 打卡条 |
| `rm NAME [--yes]` | 删除习惯及全部记录；默认先输入确认 |

全局参数：`--data PATH`（数据文件位置，默认 `~/.config/habit.json`）、`--date YYYY-MM-DD`（覆盖"今天"，仅用于测试）、`--version`。

## 设计取舍

- **连续天数是按自然日算的**：昨天和今天都打卡 = 连续 2 天；今天还没打卡不影响连续数（从昨天往前数）。
- **本周 = 自然周（周一到周日）**，不是滚动 7 天。
- 打卡记录只存日期字符串，不存时间戳——一天一次，多了不算。
- 数据文件是人类可读的 JSON，可直接备份或手改（改坏了会有明确报错而不是静默丢数据）。

## 已知局限

- 没有提醒/通知功能——想被提醒请配合 cron 或系统日历。
- 连续天数跨时区旅行时按本机日期算，出国倒时差可能"断签"，这是已知取舍。
- 多设备不做同步，数据只在本地。
